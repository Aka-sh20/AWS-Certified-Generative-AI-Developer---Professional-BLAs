## About This Repository

This repository contains my learning work from three Generative AI presentation videos.

The main purpose of this work was to understand how a Generative AI application can be improved after the basic RAG setup is working. I studied how retrieval quality can be improved, how Amazon Bedrock can add safety and control, and how AWS services can prepare different types of data before that data is used by an AI system.

The three videos are:

1. **Improving RAG Systems: Chunking, Retrieval Quality, and Multimodal Data**
2. **Building Safer and More Controlled Generative AI Applications with Amazon Bedrock**
3. **Preparing and Managing Data for Generative AI on AWS**

## What I Studied

### Video 1
I learned about RAG retrieval stages, chunking strategies, embeddings, metadata, Knowledge Base updates, RAG evaluation, LLM-as-a-Judge, and multimodal retrieval.

### Video 2
I studied Amazon Bedrock Guardrails, contextual grounding, Automated Reasoning, token-level redaction, Prompt Management, Bedrock Flows, prompt engineering, prompt injection, prompt leaking, bias, and enterprise integration.

### Video 3
I learned about Bedrock Data Automation, Blueprints, SageMaker Data Wrangler, AWS Glue, CloudWatch, Amazon Transcribe, Amazon Comprehend, and how these services can work together in a Generative AI data pipeline.
