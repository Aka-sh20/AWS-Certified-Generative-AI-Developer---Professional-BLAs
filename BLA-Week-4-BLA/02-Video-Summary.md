# Video Summary

## Video 1 – Improving RAG Systems

This video was mainly about improving the retrieval side of RAG. I learned that a RAG system can technically work but still give weak answers if it retrieves the wrong information.

The main topics were data granularity, chunking, embedding size, metadata, Knowledge Base updates, RAG evaluation, and multimodal retrieval.

The most important idea for me was that the Foundation Model can only work with the context it receives. If retrieval is poor, the final response can also be poor.

## Video 2 – Safer and More Controlled Generative AI

This video focused on controlling how a Generative AI application behaves.

I learned about Amazon Bedrock Guardrails, contextual grounding, Automated Reasoning, token-level redaction, Prompt Management, and Bedrock Flows.

It also covered prompt engineering, prompt injection, prompt leaking, bias, structured output, enterprise integration, and the AWS Well-Architected Generative AI Lens.

The main idea I learned is that a real AI application needs safety, access control, prompt design, and organized workflows in addition to the Foundation Model.

## Video 3 – Preparing and Managing Data

This video explained how data should be prepared before it is used in a Generative AI or machine learning system.

I learned about structured and unstructured data, Bedrock Data Automation, Blueprints, SageMaker Data Wrangler, AWS Glue, CloudWatch, Amazon Transcribe, and Amazon Comprehend.

The main idea was that the quality of the final AI result depends a lot on the quality and organization of the input data.
