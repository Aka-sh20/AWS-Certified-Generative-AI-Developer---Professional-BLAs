# What I Learned

From these three videos, I learned:

- A RAG system can work technically but still give poor answers if retrieval is weak.
- Chunking strategy can change the quality of retrieved information.
- Standard, hierarchical, and semantic chunking are useful in different situations.
- Embedding size affects both retrieval quality and cost.
- Metadata can help improve filtering and ranking.
- A Knowledge Base should be updated when the source data changes.
- RAG should be evaluated instead of assuming the answers are good.
- Bedrock Guardrails can help control unsafe or sensitive content.
- Contextual grounding checks if the answer is supported by the supplied information.
- Prompt Management helps reuse and version prompts.
- Bedrock Flows can connect several AI steps into one workflow.
- Prompt injection and prompt leaking are security problems.
- Structured output can make model responses easier for applications to process.
- Bedrock Data Automation can extract useful information from different media types.
- SageMaker Data Wrangler is useful for visual data preparation.
- AWS Glue can discover, catalog, transform, and check data quality.
- CloudWatch can monitor the services running in the pipeline.
- Amazon Transcribe converts speech to text.
- Amazon Comprehend analyzes text for language, sentiment, entities, and custom information.

The biggest lesson for me is that Generative AI quality depends on the full system, not only the Foundation Model.
