# Reflection – Multi-Agent Systems

This topic helped me understand why larger AI applications may need more than one agent.

A single agent can do many things, but giving it too many tools and responsibilities can make the system harder to control.

I liked the idea of specialized agents because it is similar to a real team. One person does not usually handle billing, technical support, shipping, and research at the same time.

Strands Agents helped me understand how agents can be built with useful tools. Agent Squad helped me understand how a request can be routed to the correct agent.

The biggest lesson for me was that good multi-agent design is about clear responsibilities and coordination, not just adding more agents.
