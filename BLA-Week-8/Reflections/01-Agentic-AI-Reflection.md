# Reflection – Agentic AI and Bedrock Agents

This topic changed the way I think about a Foundation Model.

Before this, I mainly thought about AI as a system that receives a prompt and creates an answer. After learning Agentic AI, I understood that the model can be part of a bigger workflow.

The agent can use tools, ask for missing information, search a Knowledge Base, and perform actions through services such as Lambda.

The part I found most useful was Agentic RAG because it showed me that retrieval does not always have to happen automatically. The agent can decide when it needs trusted information.

My main takeaway is that a good agent needs clear instructions, good tool descriptions, and the correct information before taking an action.
