# Challenges and Solutions – Multi-Agent Systems

## Challenge 1 – Why Not Use One Agent for Everything?

At first, I thought one powerful agent could just handle all tasks.

### How I Understood It

Too many tools and responsibilities can make one agent harder to manage. Specialized agents can have smaller and clearer jobs.

## Challenge 2 – Understanding Routing

I was confused about why every agent should not receive the same request.

### How I Understood It

I used the example of a receptionist. The receptionist first understands what a person needs and then sends them to the correct department.

That made intelligent routing easier to understand.

## Challenge 3 – Strands vs. Agent Squad

These two technologies looked similar in the beginning.

### How I Understood It

I remembered them like this:

Strands → Build agents and give them tools.

Agent Squad → Route and coordinate work between agents.

## Challenge 4 – Router vs. Supervisor

I initially mixed up a router and a Supervisor Agent.

### How I Understood It

A router mainly chooses where the request should go.

A Supervisor Agent can coordinate several agents and combine their results.
