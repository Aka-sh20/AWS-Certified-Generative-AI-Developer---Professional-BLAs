# Challenges and Solutions – AgentCore and Deployment

## Challenge 1 – Understanding AgentCore

At first, I thought AgentCore was another framework used to build the agent.

### How I Understood It

I learned this simple difference:

Agent framework builds the agent.

AgentCore helps operate the agent.

## Challenge 2 – Short-Term vs. Long-Term Memory

The two memory types were easy to mix up.

### How I Understood It

Short-term memory → current session.

Long-term memory → useful information from earlier sessions.

## Challenge 3 – Understanding Gateway

Gateway was difficult because it connects many outside services.

### How I Understood It

I started thinking of AgentCore Gateway as a controlled doorway between the agent and APIs, Lambda functions, or business services.

## Challenge 4 – Understanding MCP

MCP was a new concept for me.

### How I Understood It

I understood MCP as a common connection standard that helps AI applications communicate with external tools in a more consistent way.

## Challenge 5 – Human-in-the-Loop

At first, I thought advanced Agentic AI was mainly about full automation.

### How I Understood It

I learned that some decisions still need human review when the risk is high, the information is unclear, or the action is important.
