# Week 6 BLA – AWS Generative AI Developer

This folder contains my Week 6 Biweekly Learning Assessment work for the AWS Certified Generative AI Developer – Professional course.

During Week 5 and Week 6, I continued my learning from data preparation and moved into search, vector storage, database integration, and data reliability for Generative AI applications.

## Topics Covered

### Video 1 – Amazon OpenSearch: From Search Engine to GenAI Vector Store

In this part, I studied Amazon OpenSearch and learned how it can be used for search, analytics, and vector retrieval.

Main topics include:

- Documents and indices
- Primary shards and replica shards
- Managed Amazon OpenSearch Service
- Hot, UltraWarm, and Cold storage
- Index State Management
- OpenSearch security
- OpenSearch Serverless
- Semantic search and hybrid search
- Approximate Nearest Neighbor search
- HNSW and IVF
- OpenSearch as a vector store for Generative AI and RAG

### Video 2 – AWS Vector Storage Choices

In this part, I studied different AWS services that can store vectors and application data.

Main topics include:

- Amazon S3 Vectors
- Vector buckets and vector indexes
- Storing and querying embeddings
- S3 Vectors with Amazon Bedrock Knowledge Bases
- Amazon RDS
- Amazon Aurora with pgvector
- Combining SQL filtering with vector similarity
- Amazon DynamoDB
- DynamoDB for AI chat history and memory
- DynamoDB Vector Indexes
- SearchVectors API
- Choosing a storage service based on the application requirement

### Video 3 – Keeping GenAI Data Reliable

In this part, I focused on how Generative AI data can be kept updated, organized, secure, and cost-efficient.

Main topics include:

- Keeping vector stores synchronized
- Incremental updates
- EventBridge-based update workflows
- Vector index maintenance
- Reranking retrieved results
- Amazon S3 storage classes
- Durability and availability
- S3 Lifecycle Rules
- Cross-Region and Same-Region Replication
- S3 encryption methods
- Encryption in transit
- S3 Access Logs
- S3 Access Points

## What I Learned

This BLA helped me understand that building a Generative AI application is not only about selecting a Foundation Model.

The data behind the model is also very important. It needs to be stored correctly, searched efficiently, updated when the source changes, protected with security controls, and managed according to cost and access requirements.

I also learned that AWS provides different storage and retrieval services for different situations. OpenSearch, S3 Vectors, Aurora, and DynamoDB all support AI-related workloads, but each one is useful for a different type of application and data pattern.
